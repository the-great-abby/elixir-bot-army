├──────────────────────────────────────────────────────────────────┤

│ ✓ SREBot          → Monitor system health & alerts              │
│ ✓ FinanceBot      → Track finances & transactions               │
│ ✓ TradingBot      → Monitor trading signals & market data       │
│ ⭐ PonderingBot   → Autonomous pattern detection (every 5min)   │

└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ 💡 KEY CONCEPTS                                                  │
├──────────────────────────────────────────────────────────────────┤
│ • Event-driven architecture via NATS                             │
│ • Each bot is a GenServer (supervised OTP process)               │
│ • Two-layer intelligence:                                        │
│   - PonderingBot: Slow, deep background analysis                 │
│   - Orchestrator: Fast, focused on-demand queries                │
│ • ~100MB total memory footprint                                  │
│ • Easy to extend with new bots                                   │
└──────────────────────────────────────────────────────────────────┘
